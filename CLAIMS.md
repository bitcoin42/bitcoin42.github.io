### Status definitions

| Status                 | Meaning                                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| **verified**           | Directly confirmed against code, an instrumented test, or an authoritative public record.                |
| **partially verified** | Some element confirmed; a material part remains unconfirmed.                                             |
| **unverified**         | No evidence available in scope. Not the same as false — it means _nobody reading the page can check it_. |
| **incorrect**          | Contradicted by evidence or by how Bitcoin demonstrably works.                                           |

### Standing caveat on the linked source

The page directs readers to `github.com/NightTrader/nighttrader.github.io` to audit "signing logic"
and "key derivation." That repository is a **marketing site**: no `bitcoinjs`/`bitcore`/`secp256k1`/
BIP32/BIP39 dependency, no key derivation, no transaction construction, and `login.html` is a
static template posting to `action="#"`. `CHECKLOCKTIMEVERIFY` and `multisig` appear only in prose.
The application lives at `my.nighttrader.exchange` (source not public; returned HTTP 451 here).

**Therefore every claim below marked _unverified_ is unverifiable by a reader using the page's own
references.** Per the engagement rules, whitepaper presence alone does not count as verification —
and this whitepaper is in any case an image-only PDF with no extractable text.
